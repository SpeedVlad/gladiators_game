# Gladiators Game

A Java-based console battle game in which players choose between different gladiator classes and fight opponents with different abilities and statistics.

## Features

- Three playable gladiator classes
- Character statistics and combat mechanics
- Experience and level progression
- Critical attacks and shields
- Saving and loading player data

## Technologies

- Java
- Object-oriented programming
- File input and output

This project helped me develop my understanding of Java classes, game logic, data handling and problem-solving.
